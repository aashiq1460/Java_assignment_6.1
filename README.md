# Virtual Dictionary

Java assignment 6.1

A simple virtual dictionary application made with JavaFX.
The user can enter a word and click the Search button
to see its meaning.

## Features

- Search for words and display their meanings.
- Supports uppercase and lowercase input.
- Displays a message if the word is not found.
- Displays a message if the input is empty.

## Technologies

- Java 25
- JavaFX 21.0.2
- Maven
- MVC design pattern

## Project Structure

- Dictionary.java: Stores words and meanings using HashMap.
- DictionaryController.java: Handles searches and checks input.
- DictionaryView.java: Creates the user interface.
- Main.java: Starts the application.

## How to Run

1. Open the project in IntelliJ IDEA.
2. Sync the Maven project.
3. Open Main.java and run it.
4. Enter a word and click Search.
